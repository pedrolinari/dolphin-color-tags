# AI-assisted development

Dolphin Color Tags is an independent modification
of KDE Dolphin and Baloo Widgets.

## Development

Project creator and maintainer: Makita
AI development assistant: ChatGPT (OpenAI)

ChatGPT assisted with code generation, debugging,
interface design and documentation.

The project creator directed the development and
performed manual testing on Fedora Linux.

AI-generated contributions may contain errors.
Community review and contributions are welcome.

This project is not officially affiliated with
KDE or OpenAI.
